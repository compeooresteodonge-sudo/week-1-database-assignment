# week-1-database-assignment
Week 1 MySQL Database Assignment
Library Management Database

This assignment is a beginner MySQL database project based on a library management system.

The database is called library_management and contains a books table with information about books, authors, publication years, and availability.

The answer.sql file contains all the SQL commands used to create the database, create the table, insert sample books, and display the stored data.

Files
answer.sql - Contains the SQL commands for the Library Management database.
README.md - Provides a short description of the assignment.
How to Run

Open answer.sql in MySQL Workbench or MySQL Terminal and run the commands from top to bottom.
